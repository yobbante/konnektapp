# Konnekt — Transport sécurisé par scan

Plateforme marketplace de transport et logistique en Afrique.

## Stack technique

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Développement local

```sh
npm install
npm run dev
```

## Déploiement

L'application est déployée automatiquement via CI/CD.
