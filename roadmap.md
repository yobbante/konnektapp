# Audit pré-production
- [ ] Tester les entrées et réservations client de chaque mode.
- [ ] Créer des comptes de test dédiés via l’inscription normale si possible ; documenter les blocages sans contourner la confirmation.
- [ ] Auditer et tester les parcours transporteurs et administrateur accessibles.
- [ ] Vérifier les permissions actuelles et risques financiers.
- [ ] Livrer un rapport distinguant tests réussis, échecs et étapes non testées.
